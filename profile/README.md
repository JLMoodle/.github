*JLMoodle — студенческая организация разработчиков*

> Это пространство, где студенты пишут настоящий код, а JLMoodle помогает его систематизировать, проверять и оценивать. Через платформу проходят все задания: вы пишете решение, прикладываете файлы и отправляете на проверку — преподаватель видит работу, ставит оценку и оставляет комментарии.
